Setting up the tag on a phone

Three phases: back everything up, reset the phone and enroll it, then restore what belongs on it. Do them in order — the reset in phase two erases the phone completely, so nothing after that point can save something you skipped backing up first.

Written so a parent can follow it phone-in-hand. The dashed technical boxes are for whoever's running the enrollment — safe to skip if that's not you.

1

Back everything up

Ten minutes now saves every photo, chat, and app. Do all four before you touch Settings → Reset.

⚠

The reset in phase 2 is a real factory reset. It erases the phone — photos, messages, app logins, everything — back to how it left the store. Android has no "undo" for that. This phase is the only chance to save what's on the phone.

Turn on Google's device backup

Back up WhatsApp separately

Google's backup does not include WhatsApp chat history — WhatsApp keeps its own.

Copy photos and videos to a computer, too

Don't rely on cloud backup alone for photos — free Google storage runs out, and a spotty connection can leave a backup half-finished without any obvious warning. A direct copy is the belt-and-suspenders version.

Technical — see exactly what's installed before you reset

If you want a real inventory instead of trusting memory: enable Developer Options (Settings → About phone → tap Build number seven times), turn on USB debugging, plug the phone into a computer with adb installed, and run:

list every user-installed app 
adb shell pm list packages -3

That prints one package:com.example.app line per app. It's the same list Google's backup already restores automatically on sign-in — this is just for a paper record, or to sanity-check the restore in phase 3 against what was actually there before.

What actually comes back, and what doesn't

The honest version — Android's automatic backup is good, not complete.

Assuming phase 1 was done in full and the same Google account is used both sides.
On the phoneComes back howRestores?
Contacts, call history, SMS Automatic, on Google sign-in yes
Wi-Fi passwords, device & display settings Automatic, on Google sign-in yes
The apps that were installed Automatic — Android reinstalls the list from the backup yes
Paid / purchased apps Automatic, free re-download — the purchase is tied to the account yes
Data inside most ordinary apps (notes, game progress, settings) Automatic, if the app opted into Android's backup system usually
Photos & videos synced to Google Photos before the reset Automatic, downloads back down over Wi-Fi yes
Photos & videos not yet synced Only from the manual computer/USB copy in phase 1 manual only
WhatsApp chat history Manual — restore prompt inside WhatsApp itself manual only
Banking apps, and anything requiring re-login/2FA App reinstalls; sign in again inside it re-login needed
Data from apps that opt out of backup (common for banking, some games) Nothing — that app's own local data is gone no
Signal messages Only if a Signal-specific local backup was made beforehand — not covered by this guide's steps no
⚠

If an app matters and isn't in the rows above — check that app's own Settings for an export or backup option before the reset. Android's system backup only covers apps that built support for it; it can't be forced from outside.
