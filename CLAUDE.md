# Working with Daniel on this repo

- Daniel does not know coding, servers, git or this repo in depth. Do not assume he does.
- Instructions for him must be explicit and step by step: say which machine to type on (his
  Windows PC, the server over ssh, or the phone), which directory to be in, and give commands
  that can be copied and pasted as a whole. Say what output to expect.
- If a step needs something to happen in between (use the phone, wait, check a screen), split
  it into separate numbered steps rather than one block of commands.
- Do not use jargon without saying what it means in one plain sentence.
- He may make a mistake if instructions are unclear. When output looks wrong, check first
  whether the instructions were followed the intended way, and say so without blame.
- The server clone of this repo lives at /opt/Phonetagging (a second one at /root/Phonetagging).
  Scripts are run from there, not from the home directory.
- NEXT-SESSION.md is the running log of open bugs and what has been ruled out; read it first.
